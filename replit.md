# Gbemicharles Portfolio

A personal developer portfolio website built with React + Vite.

## Stack
- **Framework:** React 18
- **Build tool:** Vite 5
- **Icons:** lucide-react
- **Effects:** canvas-confetti

## Sections
Hero, About, Skills, Projects, Terminal (interactive), Experience, Contact, Footer

## Running the app
```bash
npm run dev
```
The dev server starts on port 5000. Use the **Dev Server** workflow in Replit to keep it running.

## Build for production
```bash
npm run build
```
